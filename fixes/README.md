# Fixes

Known problems in Shelvus that still need sorting out, grouped by area. Tick items off as they're done, and delete a file once everything in it is fixed.

| File | Area | Priority |
|---|---|---|
| [auth-backend.md](auth-backend.md) | Login, register, forgot-password and the user model | High |
| [registration-frontend.md](registration-frontend.md) | Register form, `useRegister` hook and form validation | Medium |
| [dependencies.md](dependencies.md) | Packages in the wrong place or unused | Medium |
| [dev-setup.md](dev-setup.md) | Things that trip up running the app locally | Low |

## Priority key

- **High**: a security hole, or a feature that silently doesn't work.
- **Medium**: wrong behaviour the user can see, or something that breaks on another machine.
- **Low**: annoyances and clean-up.
